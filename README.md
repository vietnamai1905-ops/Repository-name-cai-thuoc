# TÔI ĐÃ BỎ THUỐC — giao diện phổi tham khảo V3

Trên điện thoại: đồng hồ hành trình đặt đầu trang; tiếp đến là hình phổi minh họa, rồi đồng hồ không hút liên tục, các mốc, cài đặt, thống kê.
