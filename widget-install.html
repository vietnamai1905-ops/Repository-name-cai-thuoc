🚭 Widget cai thuốc iPhone

Đồng hồ cai thuốc trên màn hình chính, miễn phí, dùng Scriptable.

Cài đặt trong 4 bước

  1. Nhấn Sao chép mã Widget.
  2. Mở Scriptable → dấu + → dán mã → đặt tên chính xác Cai Thuoc Widget.
  3. Chạy script một lần. Có thể nhập ngày giờ hoặc quay về app web bấm Đồng bộ Widget iPhone.
  4. Giữ màn hình chính iPhone → + → Scriptable → chọn Widget nhỏ → thêm vào → giữ Widget → Sửa Widget → chọn script Cai Thuoc Widget.

Mở ScriptableTrở lại app cai thuốcWidget hiển thị ngày, giờ, phút theo các lần iOS làm mới; không nhảy từng giây liên tục. Chạm vào Widget để mở app web. Mốc cai thuốc được lưu trên iPhone.
